ScoreMindset offers a living book platform that helps individuals reflect on personal development through daily questions and evidence‑based scoring. The service provides free access to curated questions, tests, and a premium tier with additional features, while emphasizing data ownership, privacy, and zero dark‑pattern design. It is part of the ScoreZenith ecosystem and aims to empower users to assess and improve their confidence and mindset.

**Areas:** Company · Personal Development · Self Improvement · Mental Health · Education

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ScoreMindset: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
